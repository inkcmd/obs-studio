# XINKX Studio — единое рабочее пространство: ручная проверка

## Сборка

Windows x64, OBS 32.2.2 / Qt 6. Сначала собрать `obs-studio` в конфигурации `RelWithDebInfo`.

## Два холста

1. Открыть XINKX Studio с одним и с несколькими RTMP-выходами. В центральном окне постоянно видны 16:9 и 9:16, без переключателей.
2. Потянуть разделитель двух предпросмотров. Проверить изменение размеров; закрыть и открыть OBS — размер разделителя должен сохраниться.
3. В «Источниках» сверху остаётся оригинальный список OBS 16:9, снизу — самостоятельный список вертикальной композиции.
4. В 16:9 выделить захват игры. Нажать `+ Источник` в вертикальном списке → «Добавить выделенный источник 16:9 → 9:16».
5. Переместить и растянуть источник на вертикальном холсте; проверить, что горизонтальная геометрия не изменилась.
6. Отключить видимость и удалить элемент из 9:16. Убедиться, что в 16:9 он остался на месте. Повторить удаление из 16:9 и проверить, что 9:16 не затронут.
7. Переключить сцену OBS, настроить вертикальную композицию отдельно, вернуться. Проверить сохранение состава и положения.
8. Проверить клики, перетаскивание, угловые маркеры, контекстное меню, клавиши Delete и стрелки на вертикальном предпросмотре.
9. Проверить, что под двумя предпросмотрами нет огромного пустого поля «Источник не выбран»: панель свойств должна занимать высоту своего содержимого.

## Чат, элементы и пресеты

1. Запустить приложение заново: локальный чат поверх игры должен быть включён; в обычном режиме он не должен перехватывать мышь.
2. В настройках «Чат на трансляции» и «Чат поверх игры» проверить предпросмотр справа; он должен исчезать при выходе из раздела.
3. В библиотеке источников открыть «Готовые примеры XINKX» и «Мои сохранённые пресеты». Сохранить, применить, удалить свой пресет; готовые не должны удаляться.
4. Добавить таймер, растянуть его на холсте в 2–3 раза: текст и рамка должны оставаться резче, чем при внутреннем рендере 1×. В свойствах проверить «Чёткость при увеличении (1–4×)» и нагрузку GPU.

## Профили и YouTube

1. Выбрать профиль «Russian Fishing 4», закрыть и заново открыть Studio. Выбор и поля должны восстановиться.
2. Выбрать активный эфир YouTube, нажать «Проверить»: ID не должен пропасть после ответа API.
3. Проверить завершённый/удалённый эфир: показать «Недоступен / завершён», не стирать молча сохранённый ID.
4. Сохранить профиль с изменённым названием и описанием; сверить ответ API и реальные поля на YouTube. При ошибке API должен появиться текст причины.
5. Проверить донатный OAuth отдельно: пока используется callback `http://127.0.0.1:8767/oauth/callback`. Общий `8765` потребует переноса DonationAlerts в основной OAuth-сервер, который в этом патче не меняется.

## Текущая граница реализации

Штатный OBSBasicPreview по-прежнему редактирует горизонтальную сцену. Вертикальный GPU-предпросмотр использует те же libobs scene items и реализует собственные мышиные жесты/контекстные команды, но **не полную реализацию всех инструментов OBSBasicPreview** (например, его undo stack и все сочетания клавиш).
